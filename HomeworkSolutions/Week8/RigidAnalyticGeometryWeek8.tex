\par\textbf{Problem 1}\\
Since $M$ is bounded, for any $U\in\Qc(A)$ a neighbourhood of $0$, there is another neighbourhood of $0,V\in\Qc(B)$ such that  
\begin{equation*}
    VM\subseteq U.
\end{equation*}
Using that $f$ is open we see $f(U),f(V)\in\Qc(B)$ $0 = f(0)\in f(U),f(V)$, and 
\begin{equation*}
    f(V)f(M) \subseteq f(U).
\end{equation*}
For any $U'\in\Qc(B)$, $f^{-1}(U')$ is open thus if we take $U\in\Qc(X)$ such that $U\subseteq f^{-1}(U')$, we have 
\begin{equation*}
    f(U)\subseteq U'.
\end{equation*}
Thus this proves the statement.
\par\textbf{Problem 2}\\
For any open set $U\subseteq A$, the saturation of $U$ is $U+I$ which is a union of open sets thus open. Therefore the quotinet map is open, by the preious problem, the statement follows.
\par\textbf{Problem 3}\\
Clearly, for any $a\in (0,\infty)$, there is $n\in\N$ such that $r^n<a$. Thus $Y$ is topologically nilpotent. For any $a\in (0,\infty)$, then take $x\in K$ such that $\vert tx\vert >a$ for some $t\in Y$, then $a\varepsilon$ will not sit in a ball of radius $a$. This element is contained in any power of $X\cup Y$. Thus it is not topologically nilpotent.
